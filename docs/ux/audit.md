# Usability audit — StormScope as shipped (bundle DT2bjBmp / 6aHNKG35), phone 390×844

Method: every screen in `inventory/` was captured with mocked data in headed Chrome, then walked against Nielsen's ten heuristics. Screen numbers refer to `inventory/NN-*.png`. Severity: **critical** = blocks the primary task or misleads about safety; **major** = frequent friction or a dead end; **minor** = polish.

Heuristic key: H1 visibility of system status · H2 match with the real world · H3 user control & freedom · H4 consistency & standards · H5 error prevention · H6 recognition over recall · H7 flexibility & efficiency · H8 aesthetic & minimalist design · H9 help users recognise, diagnose, recover from errors · H10 help & documentation.

## Root causes (the five complaints trace to three design decisions)

1. **The home screen is a map, not an answer.** After location grant or address entry (04, 15) the only text on screen is the place name and data-freshness pills. Temperature, condition, wind and active warnings exist in the data (station obs, NWS) but are two taps away inside a tab, and "current conditions at the place" is never fetched at all (the forecast grid carries precipitation, cloud and wind but no temperature). Symptoms: complaints 1, 2, 5.
2. **One bottom sheet holds six unrelated things.** Timeline (a map control), Journey (a task), Station/Rivers/Flood (reference views), Sources (settings) share one tab row, one height, one position. Each view therefore inherits the map's state (zoom, viewport, layer toggles) instead of taking the *place* as its input. Symptoms: complaints 3, 4, 5.
3. **Map taps answer with the layer, not the place.** A tap lands on whichever layer is on top (rain cell → 24 h accumulation dialog; nothing → coordinates), so the same gesture yields different, text-heavy popups. Symptom: complaint 2.

## What is good and should survive the redesign

- Honest status language: "Hazard check failed — this is not an all-clear", per-source status lines, stale/unknown sensors never read as "no ice".
- Containment: a failing layer or panel degrades to a labelled "unavailable" state with Retry (38, 39).
- The bottom-sheet gestures after the Oct 5 fix (drag, tap, ▼, back) — they should carry over to the Map screen's details sheet.
- Replay banner (49) makes archived data unmistakable.
- The layer menu's drag-to-corner FAB (reachability) and the legend chip.
